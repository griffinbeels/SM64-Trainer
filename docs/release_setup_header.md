# 🍄 First time here? Setup takes a minute

1. **Download `SM64Trainer.exe`** from the Assets below — it's a small
   installer (~11 MB).
2. **Run it.** Windows SmartScreen will warn because the app is unsigned —
   click **More info → Run anyway**. It installs the app to
   `%LOCALAPPDATA%\Programs\SM64Trainer`, puts an **SM64 Trainer** shortcut
   on your Desktop, and launches it.
3. **Start Project64 1.6** with the **Usamune v1.93u (US)** practice ROM,
   **windowed** (replay capture can't see exclusive fullscreen). The tracker
   attaches automatically and starts recording your practice.

**Requirements:** Windows 10/11 64-bit (Windows 10 also needs the
[WebView2 runtime](https://developer.microsoft.com/microsoft-edge/webview2/) —
preinstalled on 11), Project64 **1.6** exactly, Usamune **v1.93u US**.

Your data — PBs, history, saved replays, settings — lives in
`%LOCALAPPDATA%\SM64Trainer` and survives every update. Prefer a portable
copy? Grab `SM64Trainer-full.zip` instead: extract anywhere and run the exe
inside; it self-updates in place wherever it lives.

**Already installed?** You don't need anything from this page — the app
updates itself and shows you the notes below in-app.
